# RWA Wire Growth Measurement

## Active measurement
Cloudflare Web Analytics is the source of truth for privacy-friendly traffic measurement.

Track weekly:
- Visits
- Page views
- Top paths
- External referrers
- Device mix
- Core Web Vitals

## Content groups
Use path filters to review:
- Editorial: /news/, /rwa/, /tokenization/, /institutions/
- Research map: /topics/
- Project intelligence: /projects/
- Markets: /markets/
- Learning: /learn/

## Growth funnel
1. Discovery — visits and referrers
2. Editorial engagement — article path views
3. Intelligence depth — /topics/ and /projects/ path views
4. Distribution conversion — Telegram clicks

Cloudflare Web Analytics currently does not support custom events, so step 4 is intentionally kept in the site's first-party event layer and is not falsely represented as active Cloudflare data. When an event endpoint is connected, no component rewrite is required.

## Weekly editorial questions
- Which stories generate the most discovery traffic?
- Which topic hubs gain repeat page views?
- Which project profiles attract attention after news coverage?
- Which external referrers produce the strongest readership?
- Are Core Web Vitals healthy on the highest-traffic pages?

Do not optimize editorial coverage solely for raw page views. RWA Wire's primary objective is useful, source-led intelligence and qualified repeat readership.
